# 🦆 Quackie

**Git commits with personality.**

*Write once. Quack forever.*

Quackie rewrites your Git commit messages as if they were written by a different developer personality.

Choose from 40 bundled personas:

- 🐄 Moo
- 🛡️ Repository Guardian
- 🦆 Rubber Duck
- ☕ Sleep-Deprived Senior
- 🤠 Startup Cowboy
- 🧙 Gandalf
- 💀 Doom
- ...and many more.

Works in any Git repository.

No project configuration.

No prompts.

Just install and quack.

---

## Example

Original

```text
fix: update payment flow
```

Repository Guardian

```text
🛡️ fix(payment): verify transaction lifecycle
```

Moo

```text
🐄 fix(payment): finally feed the latest prompts
```

Rubber Duck

```text
🦆 fix(payment): apparently the docs were right
```

Sleep-Deprived Senior

```text
☕ fix(payment): let's hope this one sticks
```

## Getting Started

1. Install Quackie.
2. Choose a persona.
3. Write your commit.
4. Quackie rewrites it.

That's it.

---

## Commands

| Command | Description |
| --- | --- |
| Quackie: Select Persona | Choose the active persona |
| Quackie: Commit with Persona | Preview and rewrite |
| Quackie: Rewrite Now | Rewrite immediately |
| Quackie: Toggle Auto Rewrite | Enable or disable automatic rewriting |
| Quackie: Reload Personas | Reload bundled personas |

---

## Settings

| Setting | Description |
| --- | --- |
| `quackie.persona` | Active persona |
| `quackie.autoRewrite` | Enable automatic rewriting |
| `quackie.debounceMs` | Rewrite delay |
| `quackie.apiUrl` | Rewrite endpoint |
| `quackie.enabledTargets` | Enabled rewrite targets |

---

## Privacy

Quackie never stores an API key.

When using Quackie, only your draft commit message and selected persona are sent to the Quackie rewrite service at quackie.me.
